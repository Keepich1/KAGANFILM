# KAGANFILM

Репозиторий: сайт студии (корень: `index.html`, `assets/`) и игра «Ордо» (`ordo/`, Godot 4.7). Подробности сайта — `README.md`, игры — `ordo/README.md`.

## Игра «Ордо»: как работать

- **Графика — всегда на полной мощности ultracode** (решение автора): многоагентные workflow, параллельные исполнители в отдельных
  git worktree, независимые критики с разных точек зрения и несколько кругов «кадр → разбор → исправление», пока результат не станет хорошим.
  Каждый визуальный результат рендерить (`ordo/tools/shot.sh`; на Windows — `ordo/tools/shot.cmd`), смотреть кадры и проверять панелью критиков
  (стиль ТЗ 11.1, читаемость ТЗ 11.2, техника: бюджеты ТЗ 11.5, LOD, производительность) до того, как показывать автору.
- **Остальное** (логика, инструменты, документы, сборка): где справляется один исполнитель на высоком или максимальном усилии
  (effort high/max), так и делать — без лишней оркестровки; ultracode — когда задача действительно большая или рискованная.
- Главные документы: `ordo/docs/TZ.md` (ТЗ, журнал решений в §16), `ordo/docs/CONTRACT.md` (правила кода и владельцы папок),
  `ordo/docs/ECONOMY.md` (дизайн экономики), `ordo/docs/ARCHITECTURE.md` (архитектура режима «Город»).
- Автор не программист: общение по-русски, простыми словами, со скриншотами. Перед крупной работой — согласовать кадр или макет.
- Сборка для Windows: `ordo/tools/build_windows.sh`; на GitHub установщик собирается сам (`.github/workflows/ordo-windows.yml` → Releases).
